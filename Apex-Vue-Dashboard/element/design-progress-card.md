# Progress card

## Description & use case
Shows completion against a target or a segmented operational metric.

## Anatomy & structure
- Title
- Current value
- Target or percent
- Progress track
- Optional legend

## Visual specifications
- **Surface:** Use the global surface/canvas/border tokens in `../design.md`; confirm the final values against the reference.
- **Spacing:** Use the shared spacing scale; keep padding and gaps consistent with sibling components.
- **Typography:** Apply the global type scale. Primary information should dominate supporting metadata.
- **Shape and depth:** Use the global radius and shadow tokens; avoid introducing a one-off style without visual evidence.
- **Behavioral layout:** Track uses a muted background and a clear filled portion. Include a text percentage and ensure segments have sufficient contrast.

## States & variants
- **Low/medium/high progress:** Low/medium/high progress
- **Complete:** Complete
- **Over target:** Over target
- **Loading:** Loading
